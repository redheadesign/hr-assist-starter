# Профиль и CV

1. Загрузи `scripts/hr_context.py profile`; прочитай нужный раздел `docs/operations.md`. Определи площадку и её поля, не переноси HH-структуру автоматически.
2. Проверь точность ролей, продуктов, дат, образования, контактов и источников достижений. При конфликте спроси, а не выбирай более выгодный вариант. Общий опыт считай без двойного учёта параллельных работ.
3. Для рекомендаций показывай до/после; готовые поля должны содержать только текст для вставки. Не оставляй инструкции «удалить», «уточнить» внутри готового резюме.
4. Для редактирования внешнего профиля проверь разрешение, текущую видимость и сохранение. После правки обнови страницу и проверь снимок. Фотография и публикация требуют отдельного решения, если ещё не согласованы.
5. PDF: установи необязательный `requirements-cv.txt` в окружение, используй `scripts/build_cv.py --font <TTF> --font-bold <TTF>`. Читаемая одноколоночная структура, без декора. Проверь отрендеренные страницы; не выдавай непроверенный файл как визуально проверенный.
6. Храни материалы, версии и результаты проверки только в `.local`. Подтверждённые обновления внеси в профиль и факты, чтобы будущий агент не брал старую выгрузку.
