# Первичная настройка

1. Прочитай `docs/agent-setup.md` и нужный этап `docs/onboarding.md`. Проверь Python (3.11+), затем `python -B -X utf8 scripts/setup.py init` и `status`. Зависимости ставь в `.venv`, не меняй глобальную среду.
2. Объясни: данные локальные, документы необязательны, внешние действия выключены. Начни с `next_stage`, по одному небольшому блоку вопросов. Не вываливай полный список.
3. Сохраняй ответы через `setup.py save --stage ... --json .local/inputs/...`. Пропуски через `skip`. Не пропускай от имени пользователя то, о чём ещё не спросил.
4. Предложи актуальное резюме/портфолио; остальные документы только по назначению. Для каждого объясни пользу и возможные чувствительные данные. Импортируй только явно переданные файлы через `intake.py`; не прочёсывай Downloads или почту.
5. Собери профиль и факты, уточни противоречия. Документ не даёт права опубликовать его или загрузить на сайт.
6. По docs/agent-setup.md подготовь конкретные границы чтения, откликов, бот-ответов и расписаний. Включай только по поручению владельца, уже данное согласие не спрашивай повторно. До такого поручения оставляй исходящие выключенными.
7. Покажи короткое резюме настроек и пробелы. После подтверждения сохрани этап `review`. Дай несколько примеров дальнейших запросов и напомни, что Git не содержит личную историю.

Если пользователь пришёл с конкретной вакансией, помоги с ней по доступным данным. Онбординг можно продолжить позже.
